\begin{problem}{}
Considera un conjunto de datos completos (sin datos faltantes) que te interese, con dos variables $x$, $y$. Llama a estos los ``datos completos''.

\begin{enumerate}[(a)]
  \item Escribe un programa en \texttt{R} que elimine aproximadamente la mitad de los valores de $x$. Diseña este mecanismo de no respuesta para que sea aleatorio pero no completamente aleatorio; es decir, la probabilidad de que $x$ sea faltante debería depender de $y$. Llama a este nuevo conjunto de datos (con datos faltantes en $x$) los ``datos disponibles''.
  \item Realiza la regresión de $x$ sobre $y$ (con $y$ como predictor y $x$ como respuesta) utilizando solo los datos para los que se observan ambas variables (casos completos) y demuestra que es coherente con la regresión utilizando los datos completos.
  \item Realiza la regresión de $y$ sobre $x$ usando los casos completos y demuestra que no es consistente con la regresión correspondiente utilizando los datos completos.
  \item Usando solo los datos disponibles, ajusta un modelo en \texttt{R} para $x$ dado $y$, y usa este modelo para imputar aleatoriamente los datos faltantes de $x$. Realiza la regresión de $y$ sobre $x$ utilizando este conjunto de datos imputados y compáralo con tus resultados de (c).
\end{enumerate}

\end{problem}


Para este problema, se utilizará el conjunto de datos \texttt{Salary.csv}, que contiene 35 observaciones sobre los años de experiencia y los salarios anuales (USD) correspondientes. En este conjunto de datos, la variable $x$ representa los años de experiencia (\texttt{YearsExperience}) y la variable $y$ representa el salario anual (\texttt{Salary}).

\subsection{Inciso (a)}
Se elimina aproximadamente la mitad de los valores de $x$ de manera que la probabilidad de que $x$ sea faltante dependa de $y$. El siguiente código en R realiza esta tarea:

\begin{verbatim}
set.seed(123)  # Para reproducibilidad
n <- nrow(data)
prob_missing <- plogis((data$Salary - mean(data$Salary)) / sd(data$Salary))
missing_indices <- rbinom(n, 1, prob_missing) == 1
data_available <- data
data_available$YearsExperience[missing_indices] <- NA
\end{verbatim}

El código anterior utiliza la función logística para definir la probabilidad de que $x$ sea faltante en función de $y$. Entonces, se genera un vector de índices faltantes y se asignan valores NA a los correspondientes en $x$. Este mecanismo de borrado hace que los valores faltantes en $x$ incrementen a medida que los valores de $y$ aumentan (Figura \ref{fig:missing_data}). Con este mecanismo, redujimos el número de observaciones de 35 a 20.

\subsection{Inciso (b)}
Se realiza la regresión de $x$ (Años de experiencia) sobre $y$ (Salario) utilizando únicamente los datos disponibles (casos completos). Al comparar este modelo con el ajustado sobre los datos completos, observamos una notable coherencia en las estimaciones.

El coeficiente estimado para \texttt{Salary} en el modelo con datos disponibles es $\hat{\beta}_{Salario} \approx 1.026 \times 10^{-4}$ (Error Estándar: $5.82 \times 10^{-6}$), el cual es muy cercano al obtenido con los datos completos, $\hat{\beta}_{Salario} \approx 1.105 \times 10^{-4}$ (Error Estándar: $3.66 \times 10^{-6}$). De manera similar, los interceptos son comparables: $-2.465$ frente a $-2.970$.

Esta consistencia se explica teóricamente porque el mecanismo de pérdida de datos depende exclusivamente de la variable predictora $y$ en este modelo. Al condicionar sobre $y$, la distribución de $x$ no se ve alterada por el hecho de que falten observaciones en ciertos rangos de $y$; simplemente tenemos menos información en esas regiones, lo que se refleja en errores estándar ligeramente mayores debido a la reducción del tamaño de muestra ($n=20$ vs $n=35$), pero las estimaciones puntuales permanecen insesgadas.

\subsection{Inciso (c)}
Por otro lado, al realizar la regresión inversa de $y$ (Salario) sobre $x$ (Años de experiencia) utilizando los casos completos, los resultados discrepan significativamente del modelo original.

El coeficiente para \texttt{YearsExperience} cambia de $8731.9$ (datos completos) a $9186.6$ (datos disponibles), y el intercepto disminuye de $28859.5$ a $27143.9$. Aunque a primera vista las diferencias podrían parecer moderadas, conceptualmente representan un problema grave.

La inconsistencia surge porque aquí la variable que determina la falta de datos ($y$) es la variable respuesta. Esto introduce un sesgo de selección: estamos observando preferentemente valores bajos de $y$ (dado el mecanismo diseñado en el inciso a), lo que trunca la distribución condicional de $y$ dado $x$. Como resultado, la relación estimada deja de ser representativa de la población original. Es importante notar que, aunque el mecanismo es técnicamente MAR  dado que $y$ se observa completamente, el análisis de casos completos produce estimadores sesgados cuando la probabilidad de ser observado depende de la variable respuesta.



\subsection{Inciso (d)}

Utilizando los datos disponibles, se ajusta un modelo lineal para predecir $x$ (Años de experiencia) dado $y$ (Salario). Este modelo se utiliza posteriormente para imputar los valores faltantes de $x$. La Figura \ref{fig:imputed_data} muestra los datos originales junto con los valores imputados, los cuales, al provenir de una predicción determinista (sin añadir ruido aleatorio), se alinean perfectamente sobre la recta de regresión ajustada.


\begin{figure}
  \centering
  \resizebox{0.5\linewidth}{!}{\input{figure/dataimputadaa.tex}}
  \caption{Datos disponibles con valores imputados para $x$ (Años de experiencia) utilizando un modelo ajustado de $x$ dado $y$.}
  \label{fig:imputed_data}
\end{figure}

Posteriormente, se realiza la regresión de $y$ sobre $x$ utilizando este conjunto de datos completado (imputado). Los resultados muestran un coeficiente estimado para \texttt{YearsExperience} de $9381$ y un intercepto de $25229$.

Al comparar estos resultados con los del inciso (c) (coeficiente $9186.6$), observamos que la imputación determinista ha reforzado la tendencia observada en los datos disponibles, alejándose aún más de los valores originales de los datos completos (coeficiente $8731.9$). Además, el error estándar del coeficiente ha disminuido drásticamente a $206$ (comparado con $288.8$ en los datos completos y $521.6$ en los disponibles). Esto es una consecuencia directa de la imputación simple sin componente estocástico: al rellenar los huecos con valores que caen exactamente sobre una línea, estamos artificialmente inflando la correlación ($R^2 = 0.9843$ vs $0.9652$ original) y subestimando la varianza real de los datos, lo que lleva a intervalos de confianza excesivamente optimistas y potencialmente engañosos.

\begin{problem}{}
Los datos en el archivo \texttt{Cancerdata.xls} provienen de un estudio realizado sobre el efecto del cáncer de los padres sobre los problemas de conducta en los hijos. La variable dependiente es \texttt{totbpt} que representa el puntaje total de problemas de conducta, de acuerdo a la lista de Achenbach sobre el comportamiento del Niño. Las variables género del paciente con cáncer (sexP), puntuaciones de ansiedad y depresión del paciente de cáncer (AnxtP y DeptP) y del cónyuge (AnxtS y DeptS), se consideran variables potencialmente predictoras del comportamiento de los hijos. Desafortunadamente
muchas de las observaciones son datos faltantes.  

\begin{enumerate}[(a)]
  \item Considerando solo los casos completos construye un modelo de regresion lineal múltiple para predecir la variable dependiente \texttt{totbpt} con las 5 variables predictoras mencionadas.
  \item Aplica el test de Little para probar si los datos faltantes siguen un patrón completamente aleatorio (MCAR).
  \item Aplica el enfoque de máxima verosimilitud (con algoritmo EM) o el enfoque de imputación múltiple para estimar los datos faltantes en todas las variables.
  \item Con los datos completos obtenidos en (c), construye un modelo de regresión lineal y compara los resultados con los obtenidos en (a).
\end{enumerate}
\end{problem}

\subsection{Inciso (a)}
Se ajusta un modelo de regresión lineal múltiple para predecir la variable dependiente \texttt{totbpt} utilizando las 5 variables predictoras (\texttt{SexP}, \texttt{AnxtP}, \texttt{DeptP}, \texttt{AnxtS}, \texttt{DeptS}), considerando únicamente los casos completos.

El modelo resultante se basa en solo 26 observaciones (de un total de 89), ya que 63 observaciones fueron eliminadas debido a datos faltantes. A pesar de la reducción drástica en el tamaño de la muestra, el modelo es estadísticamente significativo ($F_{5,20} = 7.706$, $p < 0.001$) y explica aproximadamente el 57.3\% de la variabilidad ajustada ($R^2_{adj} = 0.5729$).

Los coeficientes estimados son:
\begin{itemize}
    \item \texttt{DeptP}: $0.888$ ($p < 0.001$)
    \item \texttt{AnxtS}: $0.608$ ($p < 0.01$)
    \item \texttt{DeptS}: $-0.355$ ($p < 0.05$)
\end{itemize}
Las variables \texttt{SexP} y \texttt{AnxtP} no resultaron significativas en este modelo reducido.

\subsection{Inciso (b)}
Para evaluar si el mecanismo de pérdida de datos es completamente aleatorio (MCAR), se aplicó el test de Little.
La hipótesis nula ($H_0$) establece que los datos faltan completamente al azar.

El resultado del test arroja un estadístico $\chi^2 = 27.2$ con 21 grados de libertad y un valor $p = 0.163$.
Dado que $p > 0.05$, no hay evidencia suficiente para rechazar la hipótesis nula. Por lo tanto, es razonable asumir que el patrón de datos faltantes es MCAR. Esto sugiere que el análisis de casos completos realizado en el inciso (a), aunque ineficiente por la pérdida de datos, no debería estar sesgado.

\subsection{Inciso (c)}
Se procedió a imputar los valores faltantes utilizando el enfoque de Imputación Múltiple por Ecuaciones Encadenadas (MICE). Se generaron $m=5$ conjuntos de datos imputados.
Para respetar la naturaleza de las variables, se especificaron los siguientes métodos de imputación:
\begin{itemize}
    \item \texttt{logreg} (Regresión Logística) para la variable binaria \texttt{SexP}.
    \item \texttt{pmm} (Predictive Mean Matching) para las variables continuas (\texttt{Totbpt}, \texttt{AnxtP}, \texttt{DeptP}, \texttt{AnxtS}, \texttt{DeptS}).
\end{itemize}
Este enfoque permite utilizar toda la información disponible en las 89 observaciones, en lugar de limitarse a las 26 completas.

\subsection{Inciso (d)}
Se ajustó el modelo de regresión lineal a cada uno de los 5 conjuntos de datos imputados y se combinaron los resultados utilizando las reglas de Rubin (pooling).

Al comparar los coeficientes del modelo imputado (IM) con los del modelo de casos completos (CC), observamos consistencia en la dirección y magnitud de las asociaciones, pero con mejoras en la precisión (errores estándar menores) debido al aumento del tamaño de muestra efectivo.
